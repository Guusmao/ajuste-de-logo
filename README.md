# Ajuste de Logo

Ferramenta web para remover fundos de imagens, encaixar logos sem distorcer e exportar em tamanhos padrão.

## ✨ Funcionalidades

- **Remove fundo** da imagem automaticamente
- **Ajusta tolerância** e suavização de borda
- **Encaixa sem esticar** — preserva a proporção da logo
- **Dois tamanhos** padrão: 512×512 ou 1024×500
- **Fundo transparente ou customizado**
- **Exporta como PNG** pronto pra usar

## 🚀 Como usar

1. Abra o arquivo `index.html` no navegador
2. Arraste uma imagem PNG ou JPG (ou clique pra escolher)
3. Ajuste a tolerância e suavização se necessário
4. Clique na imagem pra escolher a cor do fundo
5. Escolha o tamanho final
6. Clique em "Baixar PNG"

## 📝 Ajustes disponíveis

- **Tolerância**: quão parecida a cor precisa ser pra ser removida (5-120)
- **Suavizar borda**: quão suave é a transição das bordas (0-60)
- **Tamanho final**: 512×512 (quadrado) ou 1024×500 (paisagem)
- **Fundo**: manter transparente ou usar uma cor
